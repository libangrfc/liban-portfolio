Social Media Web Application (Scrum Project)

This project was developed as a team using the Scrum development process. The goal of the project was to build a social media style web application where users can create posts, view a feed of posts, and interact with content on the website. The application was built using PHP, MySQL, HTML, CSS, and JavaScript. The system allows users to create posts, view posts in a feed, bookmark posts, and manage their own content. PHP was used for backend processing while MySQL was used as the relational database to store user accounts and posts. HTML and CSS were used to design the user interface, and JavaScript was used for interactive features.

This project was beneficial because it helped me gain experience working in a team environment using the Scrum framework. Our team worked in sprints where we completed specific goals each week. I learned how to collaborate with other developers, integrate different parts of a project, and troubleshoot issues when combining multiple files and features.

Security was also considered during development. User input validation was implemented to ensure that only correct data is processed by the system. The application also restricts users so they can only edit or delete posts that belong to their account. This type of access control helps prevent unauthorized actions within the application. Car Auction Profit Tracker

The Car Auction Profit Tracker is a web application designed to help track vehicles purchased from car auctions. The system allows users to enter information such as purchase price, repair costs, auction fees, and resale price. The application then calculates the total investment and estimated profit for each vehicle.

This project was built using PHP, MySQL, HTML, and CSS. PHP is used to process the calculations and interact with the database while MySQL stores the vehicle information. The interface allows users to easily input and manage vehicle data.

This project was beneficial because it helped me improve my backend programming and database management skills. I learned how to connect a PHP application to a MySQL database, process user input from forms, and store and retrieve information from the database.

Security practices were also considered in this project. Input validation was used to ensure that correct numeric values are entered when calculating costs and profits. This helps prevent incorrect data from being stored and reduces the risk of application errors.
